# Command Line Tic-Tac-Toe

A simple, interactive Tic-Tac-Toe game written in Python.

## How to Play
1. Run the script: `python main.py`
2. Players take turns being "X" and "O".
3. Enter a number between 1 and 9 to place your mark on the board. The board is numbered left-to-right, top-to-bottom:
   1 | 2 | 3
   ---------
   4 | 5 | 6
   ---------
   7 | 8 | 9
4. The first player to get 3 marks in a row (horizontal, vertical, or diagonal) wins!

## Requirements
- Python 3.x
